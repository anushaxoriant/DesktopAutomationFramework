# Desktop Automation Framework

Windows Desktop Automation Framework built using:

- C#
- NUnit
- FlaUI
- Allure Reporting

---

# Features

- Windows Desktop Automation
- Page Object Model
- Before Test / After Test validation
- Data Driven Testing
- Baseline File Validation
- Exception Handling
- Logging Framework
- Allure Reporting
- Dialog Handling
- Test Isolation

---

# Tech Stack

- .NET
- FlaUI
- NUnit
- Allure
- Git

---

# Framework Structure

```text
Pages
Tests
Utilities
Config
```
